The database is data/customers.db and it holds the table customers_v1 (columns id, full_name, email, phone, city, updated_at, source). Migrate it to a new table customers_v2 with the columns customer_id (integer primary key), full_name, email (lower case, trimmed), phone, city and last_contact, and remove duplicate customers. Two rows are the same customer when their emails match after trimming and lower casing. For a merged customer keep the most recent contact details.
Work through the stages in order. Use the sqlite3 command. Write the migration as a script, migration/apply.js, that you run as: node migration/apply.js run. The script may use the node:sqlite module. It may not start other programs or use the network. Stage profile: write reports/profile.json as {"row_count": <number of rows in customers_v1>}. Stage map: write migration/mapping.json as {"columns": {"<v1 column>": "<v2 column or null>"}} with every v1 column listed. Stage dedup: write migration/dedup-plan.json as {"groups": [{"email": "<lower case trimmed email>", "keep": <id of the row kept>, "drop": [<ids of the other rows>]}]} with one group for every customer, and keep the row with the most recent updated_at. Write each stage report file when the stage is done. Do not put customer emails or phone numbers in any file under reports.
